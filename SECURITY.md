# Security Policy: VerticalMap 3D

## Purpose & Scope
This project is built for **Smart India Hackathon 2026** (Problem Statement **SIH26011**) for the **Department of Land Resources (DoLR)**, Ministry of Rural Development, Government of India. It implements a prototype decision-support system for 3D ULPIN generation and vertical property mapping.

## Secret Management & Credential Handling
- **No Hardcoded Secrets**: All API keys, secrets, and environment-dependent variables are loaded via standard environment variables (`process.env`).
- **Server-Side AI API Access**: Gemini API keys and sensitive tokens are strictly kept on the server side (`server/services/geminiService.ts`) and are **never** exposed to browser bundles or client-side JavaScript.
- **Git Hygiene**: `.gitignore` strictly excludes `.env`, `.env.*`, `node_modules/`, `dist/`, build artifacts, and local log files. Only `.env.example` with placeholder strings is tracked in version control.
- **Input Validation**: All REST API endpoints enforce input parameter verification, coordinate boundary sanity checks, and safe error handling without exposing stack traces or internals to client requests.
- **Safe Security Headers**: Safe HTTP headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `X-XSS-Protection: 1; mode=block`) are enforced on the Express server.

## Prototype & Legal Disclaimer
The identifiers generated by this software (e.g., `IN-MH-PUN-P001-B01-F03-U02`) are **Candidate / Proposed 3D ULPINs** generated as prototype spatial identifiers for technical research and decision-support. They do **not** legally replace official government-issued land title records, registered sale deeds, or state cadastral registries.

## Reporting Security Issues
If you discover any security vulnerabilities or credential issues, please report them directly to the development maintainers or file a responsible disclosure report.
